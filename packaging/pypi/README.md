# headroomhq

Headroom is a self-hosted dashboard for AI account allowances, balances and usage. This wheel installs the
`headroom` command (also available as `headroomhq`).

```sh
uvx headroomhq
pipx run headroomhq
uv tool install headroomhq
pip install headroomhq
```

The wheel holds the prebuilt native binary for one platform: macOS (arm64, x86_64) or Linux (x86_64, aarch64,
glibc). There is no source distribution because there is nothing to compile.

Project: https://headroom.theblank.club
