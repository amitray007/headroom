05Statement

No cloud version.

Your server holds your tokens.

A hosted copy would keep everyone's tokens on one server that someone else runs. That is the trade Headroom refuses, so it ships no cloud version, on purpose.

You run it. One owner signs in with a passkey. Credentials are sealed with AES-256-GCM, and the master key lives outside the database.

Monitoring is read-only. It never sends a model request, redeems a reset or buys credits.
